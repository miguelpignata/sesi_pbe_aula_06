# 📚 SESI / SENAI - PBE: Aula 06

---

## 📖 Sobre a Aula

A **Aula 06** aborda a consolidação dos conceitos de desenvolvimento backend orientado a eventos, aprofundando o gerenciamento de rotas HTTP, tratamento de requisições e respostas, além da estruturação modular de aplicações em Node.js com Express.

---

## ✨ Conteúdos Abordados

- 🎯 **Rotas e Parâmetros HTTP**:
  - Leitura e manipulação de `req.params`, `req.query` e `req.body`.
  - Manipulação dos verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`).

- ⚡ **Eventos e Middlewares**:
  - Interceptação de requisições com middlewares de validação.
  - Formatação e padronização das respostas em formato JSON.

- 🛠️ **Boas Práticas**:
  - Separação de responsabilidades e organização de pastas.
  - Testes e validação das rotas com ferramentas de requisição HTTP.

---

## 🛠️ Tecnologias Utilizadas

- **[Node.js](https://nodejs.org/)**: Ambiente de execução JavaScript no servidor.
- **[Express](https://expressjs.com/)**: Framework web para criação das rotas da API.
- **[Nodemon](https://www.npmjs.com/package/nodemon)** *(dev)*: Ferramenta para reinicialização automática do servidor em ambiente de desenvolvimento.
